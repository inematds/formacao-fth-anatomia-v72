Clase 2 · 15 min

Abrir un humanoide en el simulador

La ficha técnica de un humanoide dice lo que el fabricante quiere mostrar; el archivo de simulación dice lo que el cuerpo es. En esta clase instalas MuJoCo, descargas solo los humanoides de MuJoCo Menagerie y abres el Unitree G1, leyendo del propio archivo cuántas coordenadas, velocidades y motores tiene.

Comenzar la lección

En esta lección vas a

  1. 1Qué hay en un MJCF: cuerpos, articulaciones, actuadores, sensores y poses guardadas
  2. 2El banco de trabajo en ~/fth: venv, MuJoCo 3.16.0 y Menagerie fijado en un commit
  3. 3MjModel (el cuerpo) y MjData (el estado)
  4. 4Por qué el G1 tiene nq=36, nv=35 y nu=29

Objetivo: instalar MuJoCo 3.16 y Menagerie y abrir el Unitree G1, leyendo nq, nv y nu del propio archivo MJCF.

02 · Los tres números que vas a leer en todo humanoide

Haz clic en cada uno.

1. nq = 36

La base del humanoide no está fija al suelo: es una articulación libre con 7 números (x, y, z y un cuaternión de 4 para la orientación).

Sumando las 29 articulaciones articuladas, da 36. Es el tamaño de qpos.

2. nv = 35

La base libre tiene 6 velocidades (3 lineales y 3 angulares), una menos que las 7 posiciones, porque el cuaternión tiene 4 números para 3 rotaciones.

6 + 29 = 35. Es el tamaño de qvel y de qacc.

3. nu = 29

Un actuador por articulación articulada. La base no tiene motor: el robot solo se mueve empujando el suelo con los pies.

En la versión con manos (scene_with_hands.xml) el número sube a 43. El G1 que se vende tiene de 23 a 43 grados de libertad según la versión; el Menagerie trae la de 29.

Regla prácticaHumanoide con base libre: nq = nu + 7 y nv = nu + 6, cuando cada articulación tiene un motor.

03 · Montar el banco de trabajo (una vez)

Venv propio, MuJoCo fijado en 3.16.0 y el Menagerie fijado en el commit probado. El sparse-checkout descarga solo 4 humanoides (cerca de 150 MB) en lugar del repositorio completo.

Terminal · preparar ~/fth
F=${FTH:-$HOME/fth}; mkdir -p $F && cd $F
python3.12 -m venv .venv && . .venv/bin/activate
pip install -q mujoco==3.16.0 numpy
[ -d anatomia ] || git clone -q --depth 1 https://github.com/inematds/formacao-fth-anatomia-v72 anatomia
[ -d mujoco_menagerie ] || git clone -q --filter=blob:none --sparse https://github.com/google-deepmind/mujoco_menagerie
cd mujoco_menagerie && git sparse-checkout set unitree_g1 unitree_h1 robotis_op3 booster_t1
git checkout -q 62ab00f && git log -1 --format='menagerie %h (%ad)' --date=short
python3 -c "import mujoco, numpy; print('mujoco', mujoco.__version__, '· numpy', numpy.__version__)"

05 · Lo que se usa a escala (mostrado)
