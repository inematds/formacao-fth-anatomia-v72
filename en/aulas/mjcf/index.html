Lesson 2 · 15 min

Open a humanoid in the simulator

A humanoid's spec sheet tells you what the maker wants to show; the simulation file tells you what the body is. In this lesson you install MuJoCo, download only the humanoids from MuJoCo Menagerie, and open the Unitree G1, reading from the file itself how many coordinates, velocities, and motors it has.

Start the lesson

In this lesson you will

  2. 2The workbench in ~/fth: venv, MuJoCo 3.16.0, and Menagerie pinned to a commit
  3. 3MjModel (the body) and MjData (the state)

Goal: install MuJoCo 3.16 and Menagerie and open the Unitree G1, reading nq, nv, and nu from the MJCF file itself.

02 · The three numbers you'll read on every humanoid

Click each one.

1. nq = 36

The humanoid's base is not fixed to the ground: it is a free joint with 7 numbers (x, y, z and a 4-number quaternion for orientation).

Adding the 29 articulated joints gives 36. That is the size of qpos.

2. nv = 35

The free base has 6 velocities (3 linear and 3 angular), one fewer than the 7 positions, because the quaternion has 4 numbers for 3 rotations.

6 + 29 = 35. That is the size of qvel and qacc.

3. nu = 29

One actuator per articulated joint. The base has no motor: the robot only moves by pushing against the ground with its feet.

In the version with hands (scene_with_hands.xml) the number goes up to 43. The G1 on sale has between 23 and 43 degrees of freedom depending on the version; the Menagerie ships the 29 one.

Rule of thumbHumanoid with a free base: nq = nu + 7 and nv = nu + 6, when each joint has one motor.

03 · Set up the workbench (once)

Its own venv, MuJoCo pinned to 3.16.0 and the Menagerie pinned to the tested commit. The sparse-checkout downloads only 4 humanoids (about 150 MB) instead of the whole repository.

Terminal · set up ~/fth
F=${FTH:-$HOME/fth}; mkdir -p $F && cd $F
python3.12 -m venv .venv && . .venv/bin/activate
pip install -q mujoco==3.16.0 numpy
[ -d anatomia ] || git clone -q --depth 1 https://github.com/inematds/formacao-fth-anatomia-v72 anatomia
[ -d mujoco_menagerie ] || git clone -q --filter=blob:none --sparse https://github.com/google-deepmind/mujoco_menagerie
cd mujoco_menagerie && git sparse-checkout set unitree_g1 unitree_h1 robotis_op3 booster_t1
git checkout -q 62ab00f && git log -1 --format='menagerie %h (%ad)' --date=short
python3 -c "import mujoco, numpy; print('mujoco', mujoco.__version__, '· numpy', numpy.__version__)"
Example from the repository
menagerie 62ab00f (2026-10-15)
mujoco 3.16.0 · numpy 2.5.4

Two lines and no errors. If your MuJoCo version is different, the numbers in the next lessons may change in the last digit: pin the version.

The scripts look for the Menagerie in ~/fth/mujoco_menagerie (or wherever the FTH variable points). Did you run from another folder or clone somewhere else? Adjust FTH or move the folder.

04 · Open the G1 and the other humanoids

abrir.py only reads the model and prints its size. The excerpt from g1.xml shows where the numbers come from.

Terminal · open the G1
F=${FTH:-$HOME/fth}; cd $F/anatomia && . $F/.venv/bin/activate
python3 kit/abrir.py unitree_g1/scene.xml; echo "saída: $?"
Terminal · H1, OP3 and Booster T1
F=${FTH:-$HOME/fth}; cd $F/anatomia && . $F/.venv/bin/activate
for r in unitree_h1 robotis_op3 booster_t1; do
  echo "$r: $(python3 kit/abrir.py $r/scene.xml | sed -n 2p)"
done
