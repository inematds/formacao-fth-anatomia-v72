Aula 2 · 15 min

Abrir um humanoide no simulador

A ficha técnica de um humanoide diz o que o fabricante quer mostrar; o arquivo de simulação diz o que o corpo é. Nesta aula você instala o MuJoCo, baixa só os humanoides do MuJoCo Menagerie e abre o Unitree G1, lendo do próprio arquivo quantas coordenadas, velocidades e motores ele tem.

Começar a aula

Nesta aula você vai

  1. 1O que há num MJCF: corpos, juntas, atuadores, sensores e poses salvas
  2. 2A bancada em ~/fth: venv, MuJoCo 3.16.0 e o Menagerie fixado num commit
  3. 3MjModel (o corpo) e MjData (o estado)
  4. 4Por que o G1 tem nq=36, nv=35 e nu=29

Objetivo: instalar o MuJoCo 3.16 e o Menagerie e abrir o Unitree G1, lendo nq, nv e nu do próprio arquivo MJCF.

02 · Os três números que você vai ler em todo humanoide

Clique em cada um.

1. nq = 36

A base do humanoide não está presa ao chão: é uma junta livre com 7 números (x, y, z e um quatérnio de 4 para a orientação).

Somando as 29 juntas articuladas, dá 36. É o tamanho de qpos.

2. nv = 35

A base livre tem 6 velocidades (3 lineares e 3 angulares), uma a menos que as 7 posições, porque o quatérnio tem 4 números para 3 rotações.

6 + 29 = 35. É o tamanho de qvel e de qacc.

3. nu = 29

Um atuador por junta articulada. A base não tem motor: o robô só se move empurrando o chão com os pés.

Na versão com mãos (scene_with_hands.xml) o número sobe para 43. O G1 vendido tem de 23 a 43 graus de liberdade conforme a versão; o Menagerie traz a de 29.

Regra práticaHumanoide com base livre: nq = nu + 7 e nv = nu + 6, quando cada junta tem um motor.

03 · Montar a bancada (uma vez)

Venv próprio, MuJoCo fixado em 3.16.0 e o Menagerie fixado no commit testado. O sparse-checkout baixa só 4 humanoides (cerca de 150 MB) em vez do repositório inteiro.

Terminal · preparar ~/fth
F=${FTH:-$HOME/fth}; mkdir -p $F && cd $F
python3.12 -m venv .venv && . .venv/bin/activate
pip install -q mujoco==3.16.0 numpy
[ -d anatomia ] || git clone -q --depth 1 https://github.com/inematds/formacao-fth-anatomia-v72 anatomia
[ -d mujoco_menagerie ] || git clone -q --filter=blob:none --sparse https://github.com/google-deepmind/mujoco_menagerie
cd mujoco_menagerie && git sparse-checkout set unitree_g1 unitree_h1 robotis_op3 booster_t1
git checkout -q 62ab00f && git log -1 --format='menagerie %h (%ad)' --date=short
python3 -c "import mujoco, numpy; print('mujoco', mujoco.__version__, '· numpy', numpy.__version__)"

05 · O que se usa em escala (mostrado)

Para treinar políticas com milhares de robôs em paralelo, os mesmos modelos rodam em GPU NVIDIA. Não é pré-requisito deste curso: o curso 1 da formação usa.
